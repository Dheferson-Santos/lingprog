Principais Recursos

Sintaxe Minimalista

Legibilidade de código como parte do design da linguagem, o que torna o aprendizado mais rápido e o código mais fácil de manter.

Ecossistema Amplo

Suporte para um enorme número de bibliotecas como NumPy, Pandas e TensorFlow para ciência de dados e machine learning.

Multiparadigma

Suporta programação orientada a objetos, funcional e procedural, adaptando-se a diferentes estilos de projeto.

Estrutura de Código

main.py 
def saudacao(nome, linguagem="Python"):
    return f"Olá, {nome}! Bem-vindo ao {linguagem}."

numeros = [1, 2, 3, 4, 5]
quadrados = [n ** 2 for n in numeros]

print(saudacao("Ana"))
print("Quadrados:", quadrados)
print("Soma:", sum(quadrados))
