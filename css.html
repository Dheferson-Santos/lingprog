Principais Recursos

Estrutura de Código

style.css 
.botao {
    padding: 14px 28px;
    border: none;
    border-radius: 12px;
    color: #fff;
    font-weight: 700;
    background: linear-gradient(135deg, #1572b6, #55b5ff);
    transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.botao:hover {
    transform: translateY(-4px);
    box-shadow: 0 10px 25px rgba(21, 114, 182, 0.5);
}
