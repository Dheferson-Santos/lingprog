Principais Recursos

Leve e rápida

Um interpretador minúsculo e veloz, que roda dentro de outros programas sem pesar.

Feita para jogos

Usada em Roblox, Love2D e em scripts de vários jogos, para mudar comportamentos sem recompilar.

Fácil de embutir

Se integra a programas em C e C++ para criar plugins, configurações e automações.

Estrutura de Código

main.lua 
local jogador = { nome = "Lia", vida = 100 }

function jogador:sofrerDano(valor)
    self.vida = self.vida - valor
    return self.vida
end

for golpe = 1, 3 do
    local vida = jogador:sofrerDano(20)
    print("Golpe " .. golpe .. ": vida = " .. vida)
end
